사용자가 2026-09-12에 전역 규칙(`~/.claude/CLAUDE.md`)에 한 줄을 더했다.

> 불필요한 강조 `**` 구문 사용 불가

그리고 같은 날 이 저장소의 문서에서 기존 강조를 걷어내는 일을 지시하며 이유를
적었다.

> 이것은 추론에 영향을 주지 않고 불필요한 토큰 소모를 일으킵니다. 문서 내용은
> 모두 중요하다고 생각합니다. (덜 중요한 게 없죠)

## 왜 이 규칙이 값을 하나

이 저장소의 문서는 사람이 읽기도 하지만 매 세션 컨텍스트로 올라가는 것이
주 용도다. `CLAUDE.md`는 세션마다, `HANDOFF.md`와 `docs/decisions/`는 일할
때마다 읽힌다. 강조 기호는 그 자리에서 토큰을 쓰면서 읽는 쪽의 판단을 바꾸지
않는다.

그리고 강조가 많아지면 강조가 아니게 된다. 2026-09-12 이전의
`HANDOFF.md`에는 강조가 679개 있었고, 한 문단에 셋 넷이 겹쳐서 무엇이 중요한
줄인지 가려내는 데 도움이 되지 않았다.

## 2026-09-12에 걷어낸 규모

md 파일 142개에서 13,083쌍(26,166개, 52,332바이트)을 지웠다. 파일별로는
`docs/superpowers/specs/`의 shell-memory design이 443쌍, userland-tools design이
394쌍, `HANDOFF.md`가 339쌍이었다.

## 지울 때 남겨야 하는 자리

`**`가 강조가 아니라 내용인 자리가 있다. 2026-09-12에 3,640개를 남겼다.

- 코드 블록 안(3,604개) — Zig·셸 코드와 그 주석이다. 붙여넣을 원문이라
  손대지 않는다.
- 인라인 코드 안(30개) — `char **environ`(포인터), `[_]u8{0} ** 32`(Zig의
  반복 연산자), `` `terminal: find> hl … **cur=…** us=…` ``(게이트가 찍는 로그
  문자열 그대로).
- 여러 줄에 걸친 코드 스팬 안(6개) — plan이 "3번째 줄을
  `` `**Status:** 설계 확정 …` ``로 바꾼다"처럼 넣을 글자를 적어 둔 자리다.

regex와 glob은 대개 backtick 안이나 코드 블록 안에 있어서 위 규칙에 자동으로
걸린다. 그래도 사용자가 따로 지목한 주의 사항이므로, 지우기 전에
`\*\*[/*.]`·`[/*]\*\*`·`\*\*\*` 같은 모양을 먼저 훑어 확인한다(2026-09-12에는
92곳이 걸렸고 전부 `**9회 중 2회**.`처럼 강조 뒤에 문장 부호가 붙은
오탐이었다).

## 어떻게 지우나

한 줄짜리 치환으로는 안 된다. 강조가 줄바꿈을 넘나들고(`**로그가 파이프\n버퍼보다 크면**`),
코드 스팬과 코드 블록을 가려야 한다. 2026-09-12에 쓴 방법은 세 단계다.

1. 파일을 펜스(```` ``` ````·`~~~`) 기준으로 코드 조각과 본문 조각으로 나눈다.
2. 본문 조각에서 인라인 코드 스팬을 자리 표시자로 빼낸다.
3. 남은 글자의 `**`를 앞에서부터 짝지어 지운다. 짝이 안 맞는 조각은
   손대지 않고 보고한다.

## 검증은 이렇게 한다

파일마다 고치기 전과 후의 내용을 읽어 양쪽에서 `**`를 전부 뺀 문자열이 같은지
비교한다. 같으면 지운 바이트가 `**` 외에 하나도 없다는 증명이다.

`git diff`의 `-`줄과 `+`줄을 짝지어 비교하는 방법은 쓰지 않는다. 빈 줄과 표
구분선이 있는 자리에서 diff가 정렬을 다르게 잡아서, 아무 문제가 없는데도
불일치가 나온다(2026-09-12에 116곳이 그렇게 나왔다).

## 남은 것

소스 주석에는 그대로 있다. `.zig`·`.sh`의 주석 2,209줄에 강조가 들어 있고
(`vt.zig` 229개 · `main.zig` 214개 · `input.zig` 207개 · `hangul/check.sh`
150개) 2026-09-12에는 건드리지 않았다. 사용자가 지시한 범위가 문서였고,
Zig에는 `**`가 실제 연산자로 쓰이므로 주석 줄만 골라내는 판별이 하나 더
필요하다.

줄바꿈도 다시 잡지 않았다. 줄이 강조 개수만큼 짧아져서 오른쪽이 들쭉날쭉하다.
다시 감으면 diff가 커져서 내용 변경과 구분이 안 된다.
